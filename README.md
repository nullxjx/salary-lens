# 薪资透镜 · 杭州税后收入测算

一个零运行时依赖、纯浏览器计算的中文薪资测算网页。

## 在线使用

https://nullxjx.github.io/hangzhou-salary-lens/

## 功能

- 税前月薪 4–20 万元，每档 1 万；12 薪工资 + 4 薪年终奖单独计税。
- 现金到手和含双边公积金两条收入曲线，保留年终奖换档跳变。
- 个税比例、自定义综合负担率、每涨 1 万月薪的现金年收入增量。
- 可调整双边公积金比例、月专项附加扣除、社保和公积金基数上限。
- 逐档明细、完整税额展开、CSV 明细导出、移动端适配。
- 不使用第三方统计，不上传输入，不依赖外部 CDN。

## 自定义负担率

```
1 - (税后现金 + 个人公积金 + 单位公积金) / 税前全年16薪
= (个税 + 个人社保 - 单位公积金) / 税前全年16薪
```

分母不包含单位公积金。本口径用于个人得失比较，不是法定税率或国际通用税负指标。

## 默认情景与限制

参数快照日期：2026-11-11。个人养老 8%、医疗 2%、失业 0.5%；社保月缴费基数上限 25,611 元，公积金基数上限 42,151 元，双方各 12%。个人社保各险种月缴纳额按分取整；公积金单边月缴存额按元四舍五入。

假设上一年度同薪，含奖金的年工资除以 12 作为缴费月均工资，再分别封顶；全年缴纳 12 个月。按输入参数模拟一年，不是按 2026 各月历史基数复算。不覆盖低于 4 万月薪、新入职、跨年调薪、特殊身份或其他综合所得。

工资基本减除费用每年 6 万元。年终奖采用“奖金除以 12 查月度税率，用整笔奖金乘税率、只减一次月度速算扣除数”的算法。默认单独计税，不做与并入综合所得的择优比较。

**默认政策参数来自公开资料，未自动更新，也不替代经办机构确认。**社保上限的省厅原文未能直接访问，采用媒体报道作为测算预设，并允许手动修改；页面“政策来源”列有原链接和核验限制。用于正式薪酬决策前请检查当地最新规则和工资单。不要把账户内公积金当作随时可取现金。

## 本地运行与测试

Node.js 20+ 用于测试；运行网页不需要 Node 依赖。

```sh
npm test
python3 -m http.server 8765 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:8765 。需要 HTTP 服务加载 ES modules，不要直接双击 HTML。

`tests/baseline.json` 为用 Python Decimal 独立计算的 17 档默认基线。测试覆盖逐档金额、累进税率、年终奖换档、分母口径、取整、可修改参数与无效输入。
