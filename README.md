# 薪资透镜 · 北上广深杭税后收入测算

一个零运行时依赖、纯浏览器计算的中文薪资测算网页。

## 在线使用

https://nullxjx.github.io/salary-lens/

## 功能

- 税前月薪 2–20 万元，每档 1 万；工资与年终奖月数可调，默认 12 + 4；年终奖单独计税。
- 现金到手和含双边公积金两条收入曲线，保留年终奖换档跳变。
- 个税比例、综合税率、每涨 1 万月薪的现金年收入增量。
- 可调整双边公积金比例、月专项附加扣除、社保和公积金基数上限。
- 逐档明细含全年个税和全年个人社保；综合税率支持悬停、键盘聚焦、点击查看公式。
- 完整税额展开、CSV 明细导出、移动端适配。
- 不使用第三方统计，不上传输入，不依赖外部 CDN。

## 综合税率

```
1 - (税后现金 + 个人公积金 + 单位公积金) / 税前全年收入
= (个税 + 个人社保 - 单位公积金) / 税前全年收入
```

分母不包含单位公积金。本口径用于个人得失比较，不是法定税率或国际通用税负指标。

## 默认情景与限制

参数快照日期：2026-11-11。支持北京、上海、广州、深圳、杭州 **5 个城市**。默认杭州；切换城市保留月薪、工资/奖金月数和专项扣除，重新载入该城缴费预设；“恢复默认”恢复当前城市默认参数。

| 城市 | 养老上限 | 医保上限 | 失业上限 | 公积金上限 | 个人养老/医保/失业比例 |
|---|---:|---:|---:|---:|---|
| 北京 | 36348 | 36348 | 36348 | 36348 | 8% / 2% + 3 元 / 0.5% |
| 上海 | 37731 | 37731 | 37731 | 37731 | 8% / 2% / 0.5% |
| 广州 | 27603 | 31170 | 42933 | 41697 | 8% / 2% / 0.2% |
| 深圳 | 27603 | 33633 | 48471 | 48471 | 8% / 一档 2%（二档 0.5%）/ 0.2% |
| 杭州 | 25611 | 25611 | 25611 | 42151 | 8% / 2% / 0.5% |

上限单位元/月。公积金双方各 12%；上海为基础 7% + 自愿补充 5%，分别取整，可关闭补充。社保各险种月额分别按分取整；公积金单边按元四舍五入。每城来源、适用期与核验限制见 `cities.js`，在网页中随城市同步展示。部分广深杭上限来自媒体预设，并未全部直接核验到官方原文，不能视作官方政策数据库。北京每月 3 元医保固定扣款计入个人社保及税前扣除；医保账户内部扣缴不重复扣现金。

假设上一年度同薪，含奖金的年工资除以 12 作为缴费月均工资，再分别按缴费上下限确定；全年缴纳 12 个月。按输入参数模拟一年，不是按 2026 各月历史基数复算。不覆盖低于 2 万月薪、新入职、跨年调薪、特殊身份或其他综合所得。

工资基本减除费用每年 6 万元。年终奖采用“奖金除以 12 查月度税率，用整笔奖金乘税率、只减一次月度速算扣除数”的算法。默认单独计税，不做与并入综合所得的择优比较。

**默认政策参数来自公开资料，未自动更新，也不替代经办机构确认。**社保上限的省厅原文未能直接访问，采用媒体报道作为测算预设，并允许手动修改；页面“政策来源”列有原链接和核验限制。用于正式薪酬决策前请检查当地最新规则和工资单。不要把账户内公积金当作随时可取现金。

## 本地运行与测试

Node.js 20+ 用于测试；运行网页不需要 Node 依赖。

```sh
npm test
python3 -m http.server 8765 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:8765 。需要 HTTP 服务加载 ES modules，不要直接双击 HTML。

`tests/baseline.json` 保留原杭州 17 档基线；`tests/cities-baseline.json` 是五城共 95 档独立 Python Decimal 基线，生成器为 `tests/make_city_baseline.py`。`tests/months-baseline.json` 为可调薪数的 105 个独立 Decimal 情景，含无奖金、小数薪数、最低薪数和上下限。测试覆盖逐档金额、累进税率、年终奖换档、分母口径、取整、可修改参数与无效输入。

## 可调薪数与封顶说明

- 工资发放月数 1–36，年终奖月数 0–36，支持一位小数，默认 12 + 4。它们表示月薪倍数，不是在职时长；假设全年在职，社保、公积金缴纳及专项附加扣除仍按 12 个月，基本减除费用仍为 6 万。
- 税前年收入 = 月薪 ×（工资发放月数 + 年终奖月数）；个税与综合税率的分母均使用该年收入，不含单位公积金。奖金税率查档仍用整笔奖金 ÷ 12，不除以奖金月数。
- 切换城市保留薪数；恢复默认会恢复 12 + 4。奖金填 0 时税额为 0，图表无奖金换档跳变。
- 「本档缴费基数」显示折算月均工资、各险种实际基数、上限及封顶状态；五城上限对照表显示各地独立上限。
- 示例：杭州 2 万月薪、12 + 4 情景折算月均 26,666.67 元，超过社保预设上限 25,611 元，故社保已封顶；公积金上限 42,151 元，尚未封顶。改为 12 + 0，社保基数为 20,000 元，全年个人社保为 25,200 元。
- 为支持较少薪数的情景，新增各险种下限约束。北京社保下限 7,270、公积金 2,540；上海社保 7,546、公积金 2,740；广州养老/医保/失业/公积金 5,521/6,234/2,680/2,680；深圳 5,521/6,727/2,700/2,700；杭州 5,122/5,122/5,122/2,660（市区）。来源随城市展示；部分参数来自媒体/第三方预设，不覆盖最低生活费等特殊身份。

## 界面层级

首页聚焦薪资设置、三项核心结果和趋势图。专项附加扣除及高级缴费参数放入“更多设置”；缴费基数、收入去向、五城上限和政策说明均支持按需展开，封顶状态常驻显示。综合税率公式可在结果卡或表头悬停/点击查看。计算模型和默认参数不因界面调整改变。
